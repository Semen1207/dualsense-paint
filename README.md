# dualsense-paint

A zero-dependency **Modern MS Paint** clone controlled via the **Sony DualSense** touchpad using **WebHID**. Open the HTML file in a browser, connect your controller, and draw.

## Quick Start

1. Open the link "" in **Google Chrome** or **Microsoft Edge**.
2. Connect your DualSense via **USB-C** or **Bluetooth** (close background apps like Steam Input or DS4Windows first).
3. Click **Connect DualSense** in the top-right and select *Wireless Controller*.

## Controls Summary

* **Slide Touchpad** — Move cursor
* **Click & Hold Touchpad** — Draw, select tools, and pick colors
* **Cross (`X`)** — Undo last stroke
